# Static assets

Put your logo here as **`logo.png`** (this exact path/name):

```
public/logo.png
```

It renders in the top-right of the catalogue header. Any image format works if
you also update the `src` in `components/Archive.jsx` (e.g. `logo.svg`).
A transparent PNG around 400×400 (or wider) looks best. If the file is missing,
the header simply hides the image instead of showing a broken icon.
